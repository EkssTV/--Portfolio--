#  Portfolio React 

Bienvenue sur le dépôt de mon portfolio interactif. Ce projet est une Single Page Application (SPA) moderne construite avec React, conçue pour présenter mon profil, mes réalisations et mon parcours de manière dynamique et performante.

## Objectif du projet

L'objectif est de dépasser le simple "CV au format PDF" en proposant une véritable expérience interactive. Le code est pensé pour être modulaire, facile à maintenir et évolutif.

## Architecture et Sections

Le portfolio est divisé en 5 sections principales, gérées via un routage fluide (React Router) :

1.  **Main (Accueil) :** Une Hero Section percutante présentant ma proposition de valeur.
2.  **Actualité :** Un flux dynamique mettant en avant ma veille, mes projets en cours ou mes derniers accomplissements.
3.  **Portfolio :** Une galerie de mes projets et réalisations techniques.
4.  **CV Interactif :** Une timeline retraçant mes expériences et compétences (avec possibilité de télécharger la version PDF classique).
5.  **Contact :** Un formulaire de contact et des liens vers mes réseaux professionnels.

## 🛠️ Stack Technique

*   **Framework :** React 18+
*   **Outil de build :** Vite (pour une compilation ultra-rapide et un environnement de développement optimisé)
*   **Stylisation :** Tailwind CSS (approche utilitaire pour un design responsive et sur-mesure)
*   **Routage :** React Router DOM
*   **Déploiement :** (À définir)

## 📐 Méthodologie de développement

Pour garantir un code propre et professionnel, ce projet respecte les principes suivants :

*   **Component-Driven :** Découpage de l'interface en petits composants réutilisables (Boutons, Cartes de projets, Éléments de timeline).
*   **Séparation des préoccupations :** Les données (textes des expériences, liste des projets) sont isolées du code d'affichage (dans des fichiers `.json` ou des modules de données séparés).
*   **Mobile-First :** Le design est pensé en priorité pour les petits écrans avant d'être adapté aux résolutions supérieures.

## 🚀 Installation et Lancement

Pour faire tourner ce projet en local :

1. Cloner le dépôt :
   ```bash
   git clone [URL_DU_DEPOT]
   ```
2. Installer les dépendances :
   ```bash
   npm install
   ```
3. Lancer le serveur de développement :
   ```bash
   npm run dev
   ```
